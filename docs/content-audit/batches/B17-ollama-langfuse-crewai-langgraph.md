## Batch summary

This batch is three tiers. The **ollama-on-mac** series (5 × 600–800 lines, 2026-07) is the best material here and among the best tutorial writing on the site: every CLI flag, API field, env var and quantisation ratio I checked is right (`done_reason`, nanosecond durations, `keep_alive` numeric-vs-string parsing, `format` JSON-schema, `OLLAMA_KV_CACHE_TYPE`, `think=True`/`message.thinking`, `ollama launch`, `:cloud` tags), the five parts link each other both ways, and each ends with a real decision table with flip conditions. Its faults are small: part 4 sends pip-installed Open WebUI users to port 3000 (it serves on 8080), part 5 says Ollama loads one model at a time by default (the FAQ default is 3 × GPUs), and three parts quote three different tokens/s ranges for the same 8B-Q4 model. The **langfuse-intro** series (4 × ~240 lines, 2026-06) is accurate against the v3 SDK (`observe`/`get_client`, `start_as_current_observation`, `run_experiment` + `Evaluation`, `create_prompt` labels) and clearly written, but thin — no numbers beyond one 示意 table, one trivial diagram per part, and "three observation types" is now ten. **crewai-series** is honest about version drift and uses real `crewai` APIs (`output_pydantic`, `Flow[State]`, `@router`, `and_`, `LTMSQLiteStorage`, knowledge sources), but part 3's showpiece "revision loop" calls `self.evaluate_quality()` directly, which never re-fires the `@router`, so a draft scoring < 8 is revised once and then the Flow ends without ever publishing. The third tier is the six **LangGraph** posts and the four singles dated 2026-04-11 (a batch-generation date shared by nine files): 73–89 % code by line, no thesis, no cross-links among the five "series" posts, and code that fails on first run — `invoke()` returns a dict but every post reads `result.topic`/`result.category`, the "complete, runnable" core-code post pins `langgraph==0.0.1` (no `START`) and calls an `async def execute` synchronously inside a retry loop that cannot terminate, and the ideas post `eval()`s model output. The Gemini post promises "Gemini 4" and installs Gemma 1 7B from a TheBloke repo that does not exist; the Hermes post invents `hermes start`, `hermes skills list`, `hermes schedule`, `hermes search`, `hermes reset`, a `hermes.yml` schema and a `from hermes import Skill` class; the Bedrock guide's only runnable path fine-tunes `amazon.titan-text-express-v1`, which Bedrock no longer lists as fine-tunable. Verdicts: **Ready 4** (ollama 1/2/3, langfuse 3) · **Needs revision 7** (ollama 5, langfuse 1/2/4, crewai 1/2, llm-post-training) · **Not ready 12** (ollama 4 — one-line fix; crewai 3; all six LangGraph posts; bedrock; gemini; harness; hermes).
