## Batch summary

This batch splits cleanly into three tiers. The **Cloudflare security-audit trilogy** (June 2026) is the model for the rest: thesis-first, sourced against the repo as it stood that week (five validation tests, 3-4/8-12+ agent guidance, positive-patterns section and dedup-before-validate all check out against the 2026-07-04 snapshot), with flip conditions; its only factual slip is "Cloudflare 在 2024 年開源" (repo created 2026-06-18) and a paraphrased quote. The **four claude-code-* posts** (Jan 2026) and **everything-claude-code** describe Claude Code features from memory: a non-existent built-in "Bash Agent", Skills that "cost no tokens", invented `@skill()` Python APIs, `/agent`, `claude code /code-review --pr`, `npm install -g @anthropic/claude-code`, JavaScript hooks returning `{skip:true}`, and the VS Code extension id `anthropics.claude-code`. Current docs confirm none of these; they also show that several premises (200K window, MCP tool definitions eating context) are now obsolete because 1M windows and deferred tool loading are the default. The **multi-agent token series (pt.1/5/6/7)** plus the English orchestration guide are four rewrites of the same hub-and-spoke orchestrator with the same invented 16,000-token baseline; arithmetic recomputes, but nothing is measured, pt.7 contradicts itself on coordination overhead (7,500 at L126 vs 1,500 at L1748), and pt.6 hard-codes Opus 5.5 at $15/$75 when the list price is $4/$20. Verdicts: **Ready 2** (Cloudflare pt2, pt3), **Needs revision 8** (Cloudflare pt1, context-window, token pt.1/5/6/7, best-practices, SpotifyMCP2), **Not ready 6** (both MCP tutorials, architecture-explained, dev-workflow, everything-claude-code, orchestration-agents).
