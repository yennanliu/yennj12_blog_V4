> 大多數人的做法：看到「GEO 市場 2031 年將達 73 億美元」，決定投入。
> 真正該做的事：先問這個數字是誰算的、用什麼方法算的、他賣什麼。
>
> 關於 GEO 的市場資料，絕大多數是賣 GEO 工具或服務的人寫的。
> 這一篇會盡量把「可驗證的」和「行銷內容」分開。

## 一、先講一件不舒服的事

當你搜尋「GEO 市場規模」「最好的 GEO 工具」時，前十筆結果幾乎都是：

```
來源類型                    佔比（實際搜尋觀察）   利益關係
──────────────────────────────────────────────────────────
GEO 工具商的部落格            ~40%              賣工具
GEO agency 的部落格           ~35%              賣服務
內容行銷 SaaS 的部落格         ~15%              賣寫作工具
獨立研究 / 學術                ~5%
新聞媒體                      ~5%
```

**這件事本身就很諷刺**：一個關於「如何被 AI 引用」的領域，它的資訊生態完全是被 GEO 手法優化過的內容。你讀到的每一個「市佔率 68.4%」都應該先問一句「誰量的」。

本篇的處理方式：

```
標記      意義
────────────────────────────────────────────────
[可驗證]  有公開方法論、或多個獨立來源交叉一致
[單一源]  只有一個來源，且該來源有利益關係
[推估]    我的判斷，非數據
```

```
數字                                     來源類型      怎麼讀
─────────────────────────────────────────────────────────────────

  （Mordor 預估 2030 年 1,061 億、
    Grand View 預估 1,296 億，CAGR 8-10%）

GEO 服務市場 2031 年達 73 億美元、
  CAGR 34%                              [單一源]     市場研究報告的
                                                     慣常做法是「先定義
                                                     再放大」，當方向看

AI 搜尋處理了 40% 原本會用 Google 的
  資訊型查詢（2026 年 3 月）              [單一源]     和下面那筆直接衝突
```

**最重要的一組對照**：

```
樂觀版本（多數 GEO 內容引用的）
  「AI 平台正在吃掉 15-20% 的資訊型查詢量」
  「ChatGPT 每天處理 25 億則 prompt，其中 65% 屬於搜尋性質」

保守版本（SparkToro / Datos 的 clickstream 方法論）
  「Google 處理的搜尋等價查詢，是 ChatGPT 的 373 倍」
```

兩個數字都不算錯，因為它們量的東西不同（prompt 數 vs 搜尋等價查詢數、面板組成不同）。但**如果你要跟客戶提案，你必須知道有這個保守版本存在**——因為對方的 CFO 遲早會查到。

一個誠實的說法：

```
「AI 搜尋的絕對量目前遠小於傳統搜尋，Google 仍佔約八成。
  但兩件事同時為真：
  ① 成長速度很快（各家 referral 佔比逐季變動很大）
  ② AI referral 的轉換率明顯偏高——Similarweb 的 clickstream
     資料顯示 ChatGPT referral 轉換率約 7.1%，僅次於付費搜尋
     的 7.8%，高於一般自然搜尋。

  所以這是一個『量小但質高、且成長中』的通路。
  它現在不會取代你的 SEO，但它是目前獲客成本最低的增量。」
```

**這段話比任何誇大的市場數字都好賣**，因為它經得起追問。

## 三、需求端：誰會付錢，錢從哪個口袋出

### 3.1 三種買家與他們的真實動機

```
買家類型            表面訴求              真實動機              預算來源
────────────────────────────────────────────────────────────────────────
① 焦慮型            「我在 ChatGPT      老闆自己問了 AI，      臨時追加 /
  （最常見）         上查不到自己」        發現沒有自己           行銷預備金

② 掉流量型          「自然流量掉了       想止血，且需要          原 SEO 預算
                     30%」               向上級解釋原因           （零和）

③ 前瞻型            「想提早佈局」        真的有策略，           新增預算
  （最好的客戶）                          通常已經有內部          （最好賣）
                                         數據支持
```

**辨識這三種人，決定你怎麼賣**：

```
① 焦慮型   → 賣「一次性診斷」。他要的是答案，不一定是長期服務。
             不要一開始就推 retainer，會嚇跑。
             診斷做完，約 30-40% 會轉成長期。[推估]

② 掉流量型 → 最難服務。因為 GEO 短期救不了流量（Part 1 §5：
             被引用不等於有流量）。如果你賣他 GEO 當作流量解方，
             六個月後一定翻臉。
             正確做法：老實說「GEO 不會救回你的流量，
             但它會改變你的流量結構」，然後同時處理 SEO 的問題。

③ 前瞻型   → 直接賣 retainer。這類客戶留存最好、最好合作，
             但數量最少。
```

### 3.2 一個關鍵的市場事實

```
[可驗證] 2026 Q1 的一份中型企業行銷主管調查顯示：
  58% 認為「AI 答案可見度」是優先事項
  但只有 22% 說現有的 agency 有向他們說明過怎麼處理

  → 缺口 36 個百分點
```

**這 36 個百分點就是目前的市場機會**。它不會永遠存在——一旦主流 agency 都把 GEO 加進標配（大概 12-24 個月內），這個溢價就消失了。

### 3.3 什麼樣的公司真的需要（而不是只是焦慮）

回到 Part 1 §5 的那張表，加上商業判斷：

```
公司類型              GEO 的真實價值   願付價格   服務難度   建議
─────────────────────────────────────────────────────────────────
B2B SaaS              ★★★★★          高        中        主力客群
專業服務（顧問/法律/會計）★★★★★         中高      低        主力客群
B2B 製造 / 工業品      ★★★★☆          中        高        好客戶，
                                                          但決策慢
高單價 B2C（醫美/教育） ★★★★☆          中        中
電商（品牌型）          ★★★☆☆          中        高        工程重
本地服務（餐飲/診所）    ★★☆☆☆          低        低        單價撐不起
                                                          服務成本
媒體 / 廣告變現         ★☆☆☆☆（可能為負）低        高        建議不接
                                                          （利益衝突）
```

**「媒體不接」這條要說明**：廣告變現的媒體，被 AI 摘要 = 收入流失。你能提供的價值其實是「防禦性策略」，那是另一種服務，別用 GEO 的框架賣。

### 一個結構性觀察

```
市場上的服務可以放在這張二維圖上：

              工程執行能力
                   高
                   │
     ┌─────────────┼─────────────┐
     │  ④ 獨立顧問  │  （空白）     │
     │    小團隊    │              │
     │             │  ← 這一格幾乎  │
     │             │    沒有人      │
     ├─────────────┼─────────────┤
低 ──┤             │             ├── 高   規模化能力
     │             │             │
     │  ② 內容代理  │  ③ 工具商    │
     │  ⑤ 顧問公司  │  ① SEO agency│
     └─────────────┼─────────────┘
                   │

```

**右上角（高工程能力 + 高規模化）是空的**。原因是這兩種能力的人才畫像完全不同：能改 WAF 規則、寫 schema 模板、debug SSR 的人，通常不在行銷代理商裡；而能標準化交付、管 20 個客戶的人，通常不寫程式。

**如果你有工程背景又願意做交付標準化，這是目前最明顯的空位。** Part 16 專門講怎麼填它。

### 毛利陷阱：實作專案

```
報價 NT$60 萬的四個月實作專案，實際成本結構：

  技術改造（Layer 1/2）      12 人天 × NT$8,000  = NT$ 96,000
  內容重寫（20 篇）          22 人天 × NT$6,000  = NT$132,000
  監測建置                   4 人天 × NT$8,000  = NT$ 32,000
  月度會議與報告（4 個月）     8 人天 × NT$6,000  = NT$ 48,000
  ──────────────────────────────────────────────────────
  直接成本                                       NT$308,000
  毛利                                           NT$292,000（49%）

  但實際上還會有：
  ✘ 客戶端 CMS 權限卡住 → 多 3-5 人天等待與溝通
  ✘ 內容需要領域專家審核 → 來回 2-3 輪
  ✘ 客戶臨時要加頁面 → 範圍蔓延
  → 實際毛利常掉到 30-38%
```

**內容重寫是毛利殺手**。Part 5 案例 A 中，內容佔了 48/78 人天。這也是為什麼 Part 16 會建議把內容工作**盡量留給客戶自己做**，你只提供規範、範例與審核。

## 六、這門生意最大的問題：容易被複製

誠實地說：

```
GEO 的知識門檻          進入需要多久
────────────────────────────────────────
讀完本系列 1-10 篇       2 天
把 Part 4 的腳本跑起來    半天
做出第一份診斷報告        1 週
──────────────────────────────────────
從零到能接第一個案子      約 2 週
```

**兩週。這就是門檻。** 任何宣稱 GEO 有高技術門檻的人，通常是在賣課。

所以真正的問題不是「怎麼學會」，是「為什麼客戶要找你而不是別人」。

### 六種可能的護城河，按可持續性排序

```
護城河                  可持續性   建立時間   說明
──────────────────────────────────────────────────────────────
① 產業縱深              ★★★★★     6-18 個月  你懂那個產業的
                                            查詢語言與買家行為
                                            → Part 14 的核心論點

② 自有基準資料           ★★★★★     12+ 個月   你手上有 200 個客戶
                                            的 AVS 分佈，能說
                                            「你的 23% 在同業是
                                            後段」——別人沒有

③ 工程執行能力           ★★★★☆     已有或沒有  能真的改 WAF / SSR /
                                            schema，不只給建議

④ 交付標準化             ★★★★☆     6-12 個月  同樣品質下成本更低
                                            → Part 16

⑤ 個人品牌 / 內容        ★★★☆☆     12-24 個月 你自己就是 GEO 的
                                            活案例

⑥ 工具                  ★★☆☆☆     3-6 個月   會被商業工具追上，
                                            或被開源取代
```

**第 ② 項「自有基準資料」是最被低估的**。當你服務過 30 個客戶之後，你能回答一個沒有人能回答的問題：「這個產業的引用率中位數是多少？」——這讓你的診斷報告從「這是你的數字」變成「這是你的數字，而同業中位數是 X」。**後者的說服力是前者的數倍，且無法被複製。**

從第一個客戶開始就要建這個資料庫。

## 七、市場時機：現在進場是早還是晚

```
                      2024        2026（現在）    2028（推估）
────────────────────────────────────────────────────────────────
客戶認知度              低          中高            高
  「聽過 GEO」          ~15%        ~60%           ~90%

競爭者密度              極低        中              高
  台灣專做 GEO 的團隊    個位數      數十家          數百家

服務溢價                極高        高              低
  （相對 SEO 的定價）     ×2-3        ×1.5-2         ×1-1.2

技術門檻                中          低              極低
  （工具成熟度）                     （工具已普及）    （全自動化）

主流 agency 是否標配     ✘          部分            ✔
```

**判斷**：現在是「認知度已經夠高（好賣）、但競爭還沒飽和（有溢價）」的窗口。這個窗口 [推估] 大約還有 12-24 個月。

**但要注意**：窗口關閉不代表生意消失，而是**溢價消失、變成標配**。就像 2010 年的「響應式網頁設計」——當時可以單獨收費，現在是基本要求。

所以進場的正確心態不是「賺這波」，而是「用這個窗口累積護城河 ①②③④，等溢價消失時你已經不靠溢價活著」。

## 八、三種可行的商業定位

```
╔════════════════════════════════════════════════════════════════╗
║  定位 A：產業專家（1-3 人，最推薦給獨立顧問）                     ║
╚════════════════════════════════════════════════════════════════╝
只做一到兩個產業（例如 B2B SaaS + 專業服務）
價格：診斷 NT$8-15 萬、retainer NT$8-20 萬/月
客戶數上限：6-10 個 retainer
年營收天花板：NT$800-1,500 萬
護城河：① 產業縱深 + ② 基準資料
風險：產業景氣綁定

╔════════════════════════════════════════════════════════════════╗
║  定位 B：工程交付商（5-15 人）                                   ║
╚════════════════════════════════════════════════════════════════╝
主打「別人給建議，我們直接改」
接其他 agency 與顧問公司的白牌實作
價格：專案制 NT$30-100 萬
護城河：③ 工程能力 + ④ 標準化
風險：毛利低、被客戶內化（in-housing）

╔════════════════════════════════════════════════════════════════╗
║  定位 C：診斷產品化（可小可大）                                   ║
╚════════════════════════════════════════════════════════════════╝
```

**不建議的定位**：什麼都做的全服務 agency。在你有 20 個客戶之前，聚焦的價值遠大於服務廣度。

## 十、開始之前的檢查清單

```
市場判斷
□ 你能說出保守版本的市場數字（不只樂觀版）
□ 你能回答「Google 說這就是 SEO，你怎麼看」（Part 12 §1）
□ 你知道自己要服務哪 1-2 個產業，且說得出為什麼

能力盤點
□ 你能自己改 CDN / WAF 規則嗎？（不能 → 定位 A 或找工程夥伴）
□ 你能寫 JSON-LD 模板嗎？
□ 你能建監測系統嗎？（Part 5 的腳本跑得起來嗎）
□ 你能寫出符合九條規則的內容嗎？（Part 3）

商業準備
□ 選定一種定位（A / B / C），不要三種都做
□ 定價表（診斷 / 專案 / retainer 三檔）
□ 診斷報告模板（Part 13）
□ 基準資料庫的 schema——從第 1 個客戶就開始存
□ 合約中的 KPI 寫法（Part 13 §6）

第一個客戶
□ 找一個「前瞻型」客戶，不要找「掉流量型」
□ 用低價或免費換取「可公開的案例」
□ 案例要有前後數字，且要誠實包含沒效的部分
```
